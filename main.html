Раздел 1.1
Комбинаторика
Подсчёт числа способов выбрать, расставить или распределить объекты

Три основных формулы

Сочетание
C(n,k) = n! / k!(n−k)!
Выбрать k из n. Порядок не важен.
«кто», но не «в каком порядке»
Размещение
A(n,k) = n! / (n−k)!
Выбрать k из n с порядком. Порядок важен.
«кто и на каком месте»
Перестановка
P(n) = n!
Расставить все n объектов в ряд.
«все, в любом порядке»
ℹ n! (факториал) = 1·2·3·...·n. Например: 4! = 24, 5! = 120. По определению: 0! = 1

Алгоритм выбора формулы

❶ Важен ли порядок?
Нет →Используем Сочетание C(n,k) — «выбрать команду», «выбрать лотерейные номера»
Да →Переходим к вопросу ❷
❷ Берём всех или часть?
Часть →Используем Размещение A(n,k) — «распределить медали», «составить пароль»
Всех →Используем Перестановку P(n) — «в каком порядке стоять в очереди»

Правила комбинаторики

Правило И (умножение)
N = N₁ · N₂ · ... · Nₖ
Нужно выполнить действие 1 И действие 2 — перемножаем число способов.
Правило ИЛИ (сложение)
N = N₁ + N₂ + ... + Nₖ
Подходит действие 1 ИЛИ действие 2 — складываем число способов.

Разбор задач по шагам

🏅
Задача 1 — Размещение
8 команд соревнуются в финале. Разыгрываются три медали: золотая, серебряная и бронзовая. Сколькими способами могут быть распределены медали?
1
Порядок важен? Да — золото ≠ серебро. Берём часть (3 из 8) → Размещение A(n,k)
2
Записываем формулу: A(8,3) = 8! / (8−3)! = 8! / 5!
3
Сокращаем: 8·7·6·5! / 5! = 8·7·6 = 336
✓ Ответ: A(8,3) = 336 способов
🏆
Задача 2 — Сочетание
8 команд в полуфинале. В финал попадают 3 команды (без распределения мест). Сколькими способами определятся участники финала?
1
Порядок важен? Нет — важно только кто попал, без мест → Сочетание C(n,k)
2
Записываем: C(8,3) = 8! / (3! · 5!)
3
Считаем: (8·7·6) / (3·2·1) = 336 / 6 = 56
✓ Ответ: C(8,3) = 56 способов
👥
Задача 3 — Правило И/ИЛИ
Группа: 10 юношей и 13 девушек. Сколькими способами выбрать 2 юношей И 2 девушек для олимпиады?
1
«2 юноши» — порядок не важен → C(10,2) = 10·9/2 = 45
2
«2 девушки» — порядок не важен → C(13,2) = 13·12/2 = 78
3
Нужно И юношей, И девушек → правило умножения: 45 · 78 = 3510
✓ Ответ: 3510 способов
Раздел 1.2
Случайные события
Классическое определение вероятности и алгебра событий

Основные понятия

ПонятиеОпределениеПример
Опыт / испытаниеСитуация с несколькими возможными исходамиБросок кубика
Элементарное событиеОдин конкретный исход опытаВыпало «3»
Пространство ΩПолный набор всех элементарных событий{1,2,3,4,5,6}
Случайное событиеПодмножество пространства — может произойти или нет«Чётное число»

Типы событий

Достоверное Ω — всегда происходит
Невозможное ∅ — никогда не происходит
Случайное — может произойти или нет
Равновозможные — одинаковые шансы
Несовместные — не могут быть одновременно
Совместные — могут произойти вместе

Классическое определение вероятности

Формула классической вероятности
P(A) = m / n
m — число исходов, благоприятствующих A
n — общее число равновозможных исходов
Применимо только если все исходы равновозможны и их число конечно
Свойства вероятности
Диапазон значений0 ≤ P(A) ≤ 1
Достоверное событиеP(Ω) = 1
Невозможное событиеP(∅) = 0
Противоположное событиеP(Ā) = 1 − P(A)

Разбор задач по шагам

🃏
Задача — классическая вероятность
Из колоды 36 карт вынимают одну. Найти вероятность того, что это туз.
1
Общее число исходов: n = 36 (равновозможны → можно применять формулу)
2
Число благоприятных (тузов в колоде 36 карт): m = 4
3
P(A) = 4 / 36 = 1/9 ≈ 0.111
✓ Ответ: P = 1/9 ≈ 0.111
⚪
Задача — с комбинаторикой
В урне 5 белых и 3 чёрных шара. Вынимают 2 шара. Найти вероятность, что оба белые.
1
Общее число способов вынуть 2 из 8: n = C(8,2) = 28
2
Благоприятных — выбрать 2 белых из 5: m = C(5,2) = 10
3
P(A) = 10 / 28 = 5/14 ≈ 0.357
✓ Ответ: P = 5/14 ≈ 0.357
Раздел 1.4
Геометрическая вероятность
Когда исходов бесконечно много — считаем через меры областей
⚠ Классическое определение не работает при бесконечном числе исходов (точка на отрезке, случайный момент времени). Тогда используем геометрическую вероятность.

Формулы

Универсальная форма
P(A) = mes(D) / mes(Ω)
mes — мера области (длина, площадь или объём). D — благоприятная область, Ω — вся область.
На прямой
P = l_D / l_Ω
Отношение длин отрезков
На плоскости
P = S_D / S_Ω
Отношение площадей
В пространстве
P = V_D / V_Ω
Отношение объёмов

Разбор задач по шагам

📏
Задача 1 — линейная
На отрезке [0; 1] наудачу выбирают точку. Какова вероятность, что она попадёт в промежуток [0.4; 0.7]?
1
Определяем меру: задача на прямой → используем длины
2
Длина всей области: l_Ω = 1 − 0 = 1
3
Длина благоприятной области: l_D = 0.7 − 0.4 = 0.3
4
P = 0.3 / 1 = 0.3
✓ Ответ: P = 0.3
⬛
Задача 2 — площадь
В квадрат со стороной 4 см «бросают» точку. Внутри вписан круг радиусом 2 см. Найти вероятность попадания в круг.
1
Задача на плоскости → используем площади
2
Площадь квадрата: S_Ω = 4² = 16 см²
3
Площадь круга: S_D = π·r² = π·4 ≈ 12.57 см²
4
P = 4π / 16 = π/4 ≈ 0.785
✓ Ответ: P = π/4 ≈ 0.785
💡 Главное — правильно определить какую меру использовать. Смотри на условие: точка на отрезке → длина; попадание в фигуру → площадь; попадание в тело → объём.
Раздел 2.1–2.2
Вероятность произведения и суммы
Теоремы умножения и сложения для зависимых и независимых событий

Условная вероятность

Определение
P(B|A) = P(AB) / P(A)
Вероятность B при условии, что A уже произошло. Читается: «P B при A».

Теорема умножения

Зависимые события
P(AB) = P(A)·P(B|A)
События зависимы, если наступление одного меняет вероятность другого.
Пример: шары без возврата
Независимые события
P(AB) = P(A)·P(B)
Наступление одного не влияет на другое.
Пример: два разных кубика
⚠ Из попарной независимости событий не следует их совокупная независимость!

Теорема сложения

Несовместные события
P(A+B) = P(A) + P(B)
A и B не могут произойти одновременно.
Пример: выпала чётная ИЛИ нечётная
Совместные события
P(A+B) = P(A)+P(B)−P(AB)
A и B могут произойти вместе — вычитаем пересечение, иначе посчитаем дважды.
💡 Хитрость «хотя бы один»: P(хотя бы одно из n) = 1 − P(ни одного) = 1 − q₁·q₂·...·qₙ

Разбор задач по шагам

🎯
Задача — два стрелка
Два стрелка стреляют по мишени. P(A₁)=0.7, P(A₂)=0.8. Найти: а) оба попали; б) оба промахнулись; в) попал хотя бы один; г) попал только один.
а
Оба попали — события независимы → умножаем:
P(A₁A₂) = 0.7 · 0.8 = 0.56
б
P(промах₁) = 1−0.7=0.3; P(промах₂)=1−0.8=0.2
P = 0.3 · 0.2 = 0.06
в
Хотя бы один = 1 − оба промахнулись:
P = 1 − 0.06 = 0.94
г
Только один = (1 попал, 2 мимо) ИЛИ (1 мимо, 2 попал):
P = 0.7·0.2 + 0.3·0.8 = 0.14+0.24 = 0.38
✓ а) 0.56 б) 0.06 в) 0.94 г) 0.38
⚪
Задача — шары без возврата (зависимые)
В ящике 6 белых и 8 красных шаров. Поочерёдно вынимают 2 шара (без возврата). P(оба белые) = ?
1
Без возврата → события зависимые, используем P(AB) = P(A)·P(B|A)
2
P(первый белый) = 6/14 = 3/7
3
P(второй белый | первый белый) = 5/13 (осталось 5 белых из 13)
4
P = (3/7) · (5/13) = 15/91 ≈ 0.165
✓ Ответ: P = 15/91 ≈ 0.165
Раздел 2.3–2.4
Формула полной вероятности и формула Байеса
Работа с гипотезами — причинами, через которые может наступить событие
ℹ Используем, когда событие A может наступить через одну из нескольких гипотез H₁, H₂, ..., Hₙ — взаимно исключающих и исчерпывающих причин.

Условие полной группы гипотез

Проверка гипотез (обязательно!)
P(H₁) + P(H₂) + ... + P(Hₙ) = 1
Гипотезы должны быть несовместны и образовывать полную группу. Если сумма ≠ 1 — ошибка в условии.

Формулы

Полная вероятность — ДО опыта
P(A) = Σ P(Hₖ)·P(A|Hₖ)
Зная вероятности каждой причины и вероятность A при этой причине — находим P(A) в целом.
Формула Байеса — ПОСЛЕ опыта
P(Hₖ|A) = P(Hₖ)·P(A|Hₖ) / P(A)
A уже произошло — какова вероятность, что причиной была гипотеза Hₖ? Числитель — конкретная гипотеза, знаменатель — P(A) из формулы выше.

Алгоритм решения

① Выделить гипотезы H₁...Hₙ (взаимоисключающие причины)
② Записать априорные вероятности P(Hₖ) — до опыта
③ Записать условные вероятности P(A|Hₖ) — вероятность A при каждой гипотезе
④ Контроль: проверить, что ΣP(Hₖ) = 1
⑤ Вычислить P(A) по формуле полной вероятности
⑥ Если нужно — применить формулу Байеса для нужной гипотезы

Разбор задач по шагам

🔬
Задача — контроль изделий
90% изделий стандартны, 10% — нет. Стандартное пройдёт контроль с P=0.96; нестандартное — с P=0.06. а) Найти P(пройдёт контроль). б) Изделие прошло — P(что оно стандартное)?
1
Гипотезы: H₁ = стандартное, H₂ = нестандартное
P(H₁)=0.9; P(H₂)=0.1. Контроль: 0.9+0.1=1 ✓
2
Условные вероятности:
P(A|H₁)=0.96; P(A|H₂)=0.06
а
Полная вероятность:
P(A) = 0.9·0.96 + 0.1·0.06 = 0.864 + 0.006 = 0.87
б
Формула Байеса:
P(H₁|A) = (0.9·0.96) / 0.87 = 0.864 / 0.87 ≈ 0.993
✓ а) P = 0.87 б) P(стандарт | прошло) ≈ 0.993
⚱️
Задача — две урны
Из урны 1 (5 бел, 3 чёрн) переложили 2 шара в урну 2 (2 бел, 6 чёрн). Затем из урны 2 извлекли 1 шар. а) P(белый)? б) Шар оказался белым — P(переложили разного цвета)?
1
Гипотезы о составе переложенных шаров:
H₁: 2 белых — P(H₁) = C(5,2)/C(8,2) = 10/28 = 5/14
H₂: 2 чёрных — P(H₂) = C(3,2)/C(8,2) = 3/28
H₃: 1 бел + 1 чёрн — P(H₃) = C(5,1)·C(3,1)/C(8,2) = 15/28
Контроль: (10+3+15)/28 = 28/28 = 1 ✓
2
В урне 2 стало 10 шаров. Условные вероятности достать белый:
P(A|H₁) = 4/10 (стало 4 белых)
P(A|H₂) = 2/10 (осталось 2 белых)
P(A|H₃) = 3/10 (стало 3 белых)
а
P(A) = (4/10)·(10/28) + (2/10)·(3/28) + (3/10)·(15/28)
= 40/280 + 6/280 + 45/280 = 91/280 = 13/40 = 0.325
б
Байес для H₃ (разного цвета):
P(H₃|A) = P(H₃)·P(A|H₃) / P(A) = (15/28)·(3/10) / (13/40)
= (45/280) / (91/280) = 45/91 ≈ 0.495
✓ а) P ≈ 0.325 б) P(разного цвета | белый) = 45/91 ≈ 0.495
Раздел 2.5
Схема Бернулли
Серия независимых испытаний с постоянной вероятностью успеха

Три условия схемы Бернулли

Независимость
Исход каждого испытания не зависит от предыдущих
Два исхода
Только «успех» (p) и «неудача» (q = 1−p)
Постоянство
Вероятность p одинакова для каждого испытания
⚠ Если у разных испытаний разная вероятность — схема Бернулли не применяется. Считать через обычное умножение для независимых событий.

Формула Бернулли

Вероятность ровно k успехов из n испытаний
P(k) = C(n,k) · pᵏ · qⁿ⁻ᵏ
n — число испытаний  |  k — нужное число успехов
p — вероятность успеха  |  q = 1−p — вероятность неудачи
Расшифровка множителей
C(n,k)число способов разместить k успехов среди n испытаний
pᵏвероятность k успехов подряд
qⁿ⁻ᵏвероятность (n−k) неудач подряд

Таблица типов задач

ФормулировкаФормулаПримечание
«ровно k раз»P(k) = C(n,k)·pᵏ·qⁿ⁻ᵏПрямое применение
«хотя бы один» (≥1)1 − P(0) = 1 − qⁿЧерез дополнение
«не менее k» (≥k)P(k) + P(k+1) + ... + P(n)Сумма хвоста
«не более k» (≤k)P(0) + P(1) + ... + P(k)Сумма с начала
✓ Проверка: P(0) + P(1) + ... + P(n) = 1. Если сумма ≠ 1 — где-то ошибка в расчётах.

Разбор задач по шагам

🎲
Задача 1 — ровно k успехов
Производят 4 выстрела, вероятность попадания p=0.3 при каждом. Найти P(0), P(1), P(2), P(3) попаданий.
↑
Данные: n=4, p=0.3, q=0.7. Три условия Бернулли выполнены ✓
0
P(0) = C(4,0)·0.3⁰·0.7⁴ = 1·1·0.2401 = 0.240
1
P(1) = C(4,1)·0.3¹·0.7³ = 4·0.3·0.343 = 0.412
2
P(2) = C(4,2)·0.3²·0.7² = 6·0.09·0.49 = 0.265
3
P(3) = C(4,3)·0.3³·0.7¹ = 4·0.027·0.7 = 0.076
Контроль: 0.240+0.412+0.265+0.076+P(4)≈1 ✓
✓ P(0)=0.240 P(1)=0.412 P(2)=0.265 P(3)=0.076
🎲
Задача 2 — не менее k (хвост)
5 бросков кубика. Найти вероятность того, что шестёрка выпадет не менее 3 раз.
↑
Данные: n=5, p=1/6≈0.167, q=5/6≈0.833
1
«Не менее 3» = P(3) + P(4) + P(5)
2
P(3) = C(5,3)·(1/6)³·(5/6)² = 10·(1/216)·(25/36) ≈ 0.032
3
P(4) = C(5,4)·(1/6)⁴·(5/6)¹ = 5·(1/1296)·(5/6) ≈ 0.003
4
P(5) = C(5,5)·(1/6)⁵ = 1·(1/7776) ≈ 0.0001
5
P(≥3) = 0.032 + 0.003 + 0.0001 ≈ 0.035
✓ P(≥3) ≈ 0.035
🏹
Задача 3 — хотя бы один
Стрелок попадает в мишень с вероятностью p=0.8. Производится 5 выстрелов. Найти P(хотя бы одного попадания).
1
«Хотя бы одно» — считаем через дополнение: P = 1 − P(0)
2
P(0) = C(5,0)·0.8⁰·0.2⁵ = 1·1·0.00032 = 0.00032
3
P(≥1) = 1 − 0.00032 = 0.99968
✓ P(хотя бы одно попадание) ≈ 0.9997
