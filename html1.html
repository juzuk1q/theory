11
Словарь программы
Vocabulary
n = n₁ + n₂

n₂число уникальных операндов (переменные, константы)
Словарь — это сколько «разных слов» знает программа.

N = N₁ + N₂
N₁общее число вхождений операторов (каждое использование)
N₂общее число вхождений операндов
Длина — сколько «слов» написано, с повторами.

Метрика Чепина (Chapin)
6
Метрика ввода-вывода Чепина
Chapin's I/O metric
Q = a₁P + a₂M + a₃C + a₄T Стандартные коэффициенты: Q = 1P + 2M + 3C + 0.5T
P
Вес: 1
Переменные, используемые только для ввода данных
M
Вес: 2
Переменные, модифицируемые в модуле (ввод + вывод)
C
Вес: 3
Управляющие переменные — влияют на поток выполнения
T
Вес: 0.5
Паразитные переменные — неиспользуемые, избыточные
Оценивает информационную прочность программного модуля путём анализа характера использования переменных из списка ввода-вывода.
10
Полная метрика Чепина
Full Chapin metric
Q_полн = Q_ввода + Q_вывода
Анализируется список переменных ввода и вывода по отдельности — каждый делится на P, M, C, T. Итоговый Q считается для каждого списка, затем суммируется.
Метрики размера и сложности кода
5
SLOC — исходные строки
Source Lines Of Code
SLOC = все строки кода
Включает: исполняемые строки + комментарии + пустые строки. Считается весь исходный текст программы как есть.
4
ELOC — исполняемые строки
Executable Lines Of Code
ELOC = SLOC − N_ком − N_пуст
N_комстроки с комментариями
N_пустпустые строки
Только реально исполняемый код — без балласта комментариев и пустых строк.
13
Цикломатическая сложность (Мак-Кейба)
McCabe's Cyclomatic Complexity
V(G) = e − n + 2p При p = 1 (одна функция): V(G) = e − n + 2
eчисло дуг (рёбер) в графе потока управления
nчисло вершин (узлов) в графе
pчисло компонентов связности (обычно 1)
⚡ Быстрый способ: V(G) = количество условных операторов (if, while, for, case, &&, ||) + 1

Интерпретация: 1–10 — простая (хорошо) · 11–20 — умеренная · 21–50 — сложная · >50 — очень сложная
Метрики стилистики и комментированности
12
Уровень комментированности
Comment ratio
C_rate = N_ком / N_стр
N_комчисло комментариев в программе
N_стрчисло строк (операторов) исходного текста
Код делится на равные части, для каждой вычисляется коэффициент — показывает плотность документирования.
7
Метрика стилистики
Style metric
S = f(C_rate, именование, отступы, структура)
Взвешенная оценка читаемости кода. Учитывает: плотность комментирования, соглашения об именовании, отступы, длину функций. Итоговый балл — сумма всех компонентов с весами.

DIT = max(уровней наследования)
DIT = 0 у корневого класса. Рекомендуется DIT ≤ 5. Чем глубже — тем сложнее понять поведение класса.

CBO — Coupling Between Objects
CBO = число связанных классов
Количество классов, с которыми данный класс имеет связь. Рекомендуется CBO ≤ 5. Высокий CBO → хрупкость системы.

Метрика Чепина — детально
Суть: Оценить информационную прочность модуля через анализ того, как используются переменные. Каждая переменная из списка ввода-вывода относится ровно к одной из 4 групп.
6

Полная метрика (оба списка)
Q_полн = Q_ввода + Q_вывода
Считаем Q отдельно для списка ввода и для списка вывода, затем складываем.
Классификация переменных (алгоритм)
КлассВесПризнакПример
P 1 Только читается, не изменяется, не управляет потоком int a = input();
M 2 Читается И изменяется внутри модуля (in/out) sum += a;
C 3 Определяет поток выполнения (условия, флаги) if (flag) { … }
T 0.5 Паразитная: не используется или избыточна int unused = 0;

Объектно-ориентированные метрики
Применяются к ООП-коду. Оценивают структуру классов: насколько глубока иерархия наследования и насколько классы зависят друг от друга.
1a
DIT — Глубина наследования
Depth of Inheritance Tree
DIT = max(уровней наследования)
DIT=0корневой класс (не наследует ничего)
DIT=1наследует от корня
DIT=NN уровней вложенности наследования
Рекомендуемое значение: DIT ≤ 5. Глубокие иерархии трудно понять и изменить.
1б
CBO — Взаимозависимость
Coupling Between Objects
CBO = |{ связанных классов }|
Связькласс A использует методы/поля класса B, или B использует A
Рекомендуемое значение: CBO ≤ 5. Высокий CBO → система хрупкая, изменения в одном классе ломают другие.
МетрикаНормаЧто означает нарушение
DIT > 5 ⚠️ Высокое Сложно понять, какие методы унаследованы. Высокий риск ошибок.
CBO > 5 ⚠️ Высокое Класс слишком зависим — трудно переиспользовать и тестировать.
